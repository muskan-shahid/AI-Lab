# Lab 1 – Travel Agent

## 📌 Project Overview

This project is a simple **Travel Agent** developed in Python as part of Lab 1.

## ✈️ Features

* Provides travel-related assistance
* Takes user input
* Generates travel information and recommendations
* Uses **if and else conditions** for decision-making

## 🛠️ Technologies Used

* Python

## 🧠 Python Concepts Used

* User Input
* Variables
* `if` condition
* `else` condition
* Conditional decision-making
* Print statements

## 📂 Project File

* `travel_agent.py`

## ▶️ How to Run

```bash
python travel_agent.py
```
